# Personal Portfolio Website

A clean and fully responsive personal portfolio website built with HTML and CSS. This project demonstrates modern web development concepts such as layout design, responsive structures for all screen sizes, and clean, user-friendly styling — a step in improving my web development skills.

## Features

- Fully responsive design for desktops, tablets, and mobile devices.  
- Clean, modern, and easy-to-navigate layout.  
- Built entirely with HTML and CSS, no frameworks used.  
- Sections for personal info, projects, skills, and contact details.  

## Usage

- Explore sections to view personal info, projects, and skills.  
- Use the contact form (if implemented) to get in touch.  

## Technologies Used

- HTML  
- CSS  
- normalize.css (for consistent styling across browsers)  
- Minified CSS files for optimized loading
